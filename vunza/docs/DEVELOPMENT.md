# Desenvolvimento

## Comandos

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm typecheck
pnpm test
```

## Prisma

```bash
pnpm db:generate
pnpm db:push
pnpm db:migrate
pnpm db:studio
```

Durante desenvolvimento rápido, `db:push` pode ser usado. Para histórico controlado de produção, prefira migrations.

## Git

```bash
git init
git add .
git commit -m "chore: initialize VUNZA Fase 1"
git branch -M main
git remote add origin SEU_REPOSITORIO
git push -u origin main
```
